# Staging runbook — external control-plane actions

Ordered operator instructions for everything the repository cannot do for itself. Each step names the exact setting, why it exists, how to verify it, how to roll it back, who owns it, and the terminal state to record in [`evidence-register.md`](evidence-register.md). Nothing here was performed by BRAND_R0's repository work; a runbook is not a completed configuration.

Owner shorthand: **OWN** = repository owner (Nathaniel Walker) or a delegate with admin on the named service.

Do these in order: A → B → C → D → E, then F and G in parallel. B depends on A.7 (required checks) only for "Wait for CI"; C must exist before B.4 (staging variables).
