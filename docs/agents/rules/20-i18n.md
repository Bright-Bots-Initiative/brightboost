# i18n rules

- Never hardcode user-facing English in JSX or UI components. Use `useTranslation()` keys.
- New copy lands in `en.json` **and** `es.json` at minimum; add `vi` / `zh-CN` when practical. Uncertain translations: English value + `// TODO: translate`.
- Locale files: `src/locales/{en,es,vi,zh-CN}/{common,pathways}.json` — one `translation` namespace, merged at boot.
- Game / content data (non-UI): `pickLocale()` from `src/utils/localizedContent.ts`.
- DB-sourced module/activity names: `translateContentName()`.
- Glossary: terms live under `pathways.glossary.terms.<slug>.*` in locale JSON; `src/data/glossary.ts` holds slug + category only.
- Architecture and backlog: `docs/i18n.md`.
