# The Great Work playable studio

**Request.** Implement the K–2 save, reopen, revise and duplicate milestone, and open a playable demo.

**Scope.** Use the existing machine engine and builder for the student studio and guest demo. Give children a working starting machine, a short English/Spanish lesson and a name they can choose without typing. The guest demo keeps its shelf in the browser. Student creations use the signed-in course shelf.

**Related work.** [Persistence #722](https://github.com/Bright-Bots-Initiative/brightboost/issues/722), [starter content #723](https://github.com/Bright-Bots-Initiative/brightboost/issues/723), [Creator Studio #724](https://github.com/Bright-Bots-Initiative/brightboost/issues/724).
