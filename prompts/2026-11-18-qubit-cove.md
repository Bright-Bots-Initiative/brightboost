# Qubit Cove

User request: “create the first game for k-2 using the quantum specialty. Should be based on super mario 64”

Build an original exploration platformer for the Bright Boost Quantum specialty.
Use a lighthouse hub, three freely ordered beacon experiments, optional sparks,
and forgiving jumps. Let learners prepare and measure simulated qubits with
certain and equally likely outcomes. Keep the existing Set 3 specialty gate and
activity completion flow.
